The look

Glass, not boxes

A card is a translucent dark fill over the background. No neutral borders.

A ring is a signal

An outline appears only when it means something: the main thing, or something at stake.

One accent

A single bright accent on a dark stage. Everything else is white at different opacities.

Two typefaces

A condensed display face for numbers and headings, a plain sans for text.

Light, not motion

Feedback under 300 ms, nothing bounces. Reduced motion turns it all off.

Keyboard first

A button can show and own its hotkey. Layers close in order on Esc.

Components

Button

An action. One accent button per screen is the main thing; the rest stay quiet. A button can display its hotkey and own it.

<template>
  <OButton variant="primary" size="lg" hotkey="Enter" @click="save">
    Save changes
  </OButton>
  <OButton size="lg" @click="cancel">Cancel</OButton>
</template>

Variants

Five levels of weight. Use primary once per screen.

<OButton variant="primary">Primary</OButton>
<OButton>Secondary</OButton>
<OButton variant="soft">Soft</OButton>
<OButton variant="ghost">Ghost</OButton>
<OButton variant="link">Link →</OButton>

Sizes and shapes

Three sizes, a pill shape for navigation, and an icon-only button.

Hotkey

Pass a physical key code (KeyboardEvent.code): the button shows the key and reacts to it on any layout. The key is ignored while the user types in a field, with modifiers held, and on key repeat.

<OButton variant="soft" hotkey="KeyR" @click="retry">Retry</OButton>
